## Checks that fail the build

`npm run build` = `prebuild` (content checks) → `next build` → `postbuild` (`scripts/check-build.mjs` against `next start`):
- every restored URL returns 200 with the tool in the server HTML;
- no link to an external host outside the reference allowlist;
- every redirect is one hop to a 200, on www and on the apex host; every internal link returns 200;
- no URL with Bing clicks before Nov 5 returns 404/410 unless listed with a reason in `research/bing/allowed-gone.json` (currently none);
- sitemap lastmod values are not all the same date, and every sitemap URL returns 200;
- no two indexable pages share more than 30% masked prose.

## Bing routine

- `npm run bing`: pulls query, page, traffic, crawl, sitemap and link data into `research/bing/YYYY-MM-DD/` and writes the weekly report (queries entering/leaving the top 3, #4–10 by impressions, top-5 queries under 10% CTR, new 4+ word queries, Copilot citations by page, clicks per day vs last week, experiments due) to that folder and `docs/bing-weekly.md`. Drop the two AI Performance CSV exports in the folder first for the citation section.
- `npm run bing -- --url /path`: Bing clicks, impressions and citations for one URL. Required before any prune, redirect or merge.
- Fix at most 3 pages a week; log each in `docs/bing-experiments.md`; `npm run indexnow -- --urls <those paths>` after the deploy. IndexNow now refuses to submit the whole sitemap unless `--all` is passed.
- Monthly: Bing Site Scan (Bing UI), refresh years and test dates where content changed.
- Query map: `docs/bing-query-map.md` (one owner per family; regenerate with `node scripts/query-map.mjs`).
